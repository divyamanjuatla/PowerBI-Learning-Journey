# 📊 Day 1 of My Power BI Learning Journey

Today I started learning Power BI as part of my journey toward becoming a Data Analyst.

## 🤔 Why Power BI when we already have Excel?

Excel is great for data analysis, but Power BI is especially useful when we need:

- Automation
- Data refresh
- Multiple data sources
- Interactive dashboards
- Better sharing and access control

## 📊 What is Business Intelligence?

Business Intelligence (BI) is the process of collecting, cleaning, analyzing, and visualizing data to help businesses make better decisions.

## 📈 What is Data Visualization?

Data visualization is the process of converting data into charts, graphs, and other visuals to make complex information easier to understand.

## 🧩 Components of Power BI

### Power BI Desktop
Used for data preparation, data modeling, DAX, and creating reports and visuals.

### Power BI Service
A cloud platform used to publish, share, and collaborate on Power BI reports.

### Power BI Mobile
Allows users to access and monitor reports and dashboards from mobile devices.
